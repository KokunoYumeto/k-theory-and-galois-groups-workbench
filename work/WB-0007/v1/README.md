# Relation (IV) of Nakamura and Schneps holds on the profinite Grothendieck-Teichmüller group, with an application to the two elliptic points of the modular curve

WB-0007, version 1, deposited on Hexagon on 23 November 2026.

Nakamura and Schneps (2000) defined a subgroup of the profinite Grothendieck-Teichmüller group GT-hat by two
relations, (III') and (IV), that hold for Galois elements, and left open whether it is all of GT-hat; Lochak,
Nakamura and Schneps still called this unclear in February 2026. This work proves that (IV) holds for every
element of GT-hat, so that every element of GT-hat is a Galois element times an element of the group Lambda of
Hatcher, Lochak and Schneps, which acts on the whole tower of pure mapping class groups. As an application, a
level-twelve character comparing the frames at the two elliptic points of the modular curve vanishes on the
normalized elements.
